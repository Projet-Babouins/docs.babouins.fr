Ce cours sert d'exemple. Il se modifie depuis l'éditeur, sur [/admin](/admin).

## Écrire un cours

* Un titre suffit pour créer un cours.
* Le dossier choisi range le cours dans la barre latérale.
* Le contenu s'écrit en Markdown : titres, listes, images, blocs de code.

```bash
echo "Bonjour les babouins"
```
